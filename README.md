# Detection Engineering Queries

A personal collection of detection rules for various SIEM and EDR/XDR platforms. Content is derived from real-world attack techniques, threat intelligence, and hands-on testing. My goal is to provide adaptable detection logic that others can tune and apply to their own environments.

Each rule published will contain the following metadata:

- Description: A brief overview of the rule and the activity it is designed to detect.
- Severity: The severity of the rule. Values can be Low, Medium, High, or Critical.
- Blind Spots: Scenarios in which the rule may fail to detect the intended activity.
- Common False Positives: Common legitimate activities that may trigger the rule.
- Investigation Guidelines: Guidance for analysts investigating alerts generated by the rule.
- References: Links providing additional context about the rule's logic, techniques, or origins.
- Query: The detection query, written in the query language supported by the target platform.
- MITRE ATT&CK: Relevant MITRE ATT&CK tactics and techniques associated with the detection.
- Version History: A record of changes made to the rule over time.
